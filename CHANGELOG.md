# Changelog

## 0.1.0 — Initial implementation

- Added a dependency-free local repository inspector.
- Detected common project manifests, language signals, scripts, tests, documentation, license, and CI configuration.
- Added evidence-based README rendering with install guidance, script references, repository structure diagrams, and contribution instructions.
- Added CLI operations for inspection, generation, and stale-documentation checking.
- Added bounded scanning, common ignore rules, symlink skipping, and atomic output writes.
- Added tests, examples, visual design assets, and cross-platform CI.

ReadmeForge is alpha software. Generated documentation should be reviewed before publishing.
